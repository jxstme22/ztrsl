# Discord setup

- Discord `Settings → Voice & Video`: **Output Device** → CABLE Input.
- yTSRL: a "Discord Call" source (tag DISCORD), natural-conversation VAD.
- Route Discord and a game into the same cable to treat them as one
  source, or use a second cable for separate `[TEAM]`/`[DISCORD]` lanes
  (Live → Capture mode: All sources).
