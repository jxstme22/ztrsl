# Architecture Decision Records

ADRs document binding choices and justified deviations from the specification hierarchy.

Statuses:

- **Proposed**: under review;
- **Accepted**: current architecture;
- **Superseded**: replaced by a later ADR;
- **Rejected**: evaluated but not adopted.

Create new records from `ADR-TEMPLATE.md`. Never rewrite an accepted decision to hide a change;
supersede it with a new ADR.
