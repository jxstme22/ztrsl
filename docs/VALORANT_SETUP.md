# VALORANT setup

- VALORANT `Settings → Audio → Voice Chat`: **Output Device** → CABLE Input.
- VALORANT `Settings → Audio`: **Speaker/Output** stays on your headphones.
- yTSRL: source "Valorant Team" (tag TEAM), source language Filipino (or
  Chinese for Mandarin parties), output English/Chinese.
- Use the **fast_callouts** VAD profile (default for the VALORANT preset).
- Sanity check in **Diagnostics**: run the isolation test with game audio
  playing and no one speaking — the voice meter must stay near-silent.
