# Quick start

1. Install the app from [GitHub Releases](https://github.com/jxstme22/ztrsl/releases/latest).
2. On Windows, install **VB-CABLE** from vb-audio.com (the app detects it
   but never bundles it). On macOS, install **BlackHole**.
3. Open the app → **Sources**: add a source, pick its audio input
   (CABLE Output for routed voice chat, a microphone, or a loopback).
4. **Live** → pick the source language, output language, quality, and
   ASR/translation providers (local models install from the **Models**
   page; cloud endpoints accept a free API key).
5. Press **Start listening** — captions appear on the transparent overlay.

See `docs/VIRTUAL_CABLE_SETUP_WINDOWS.md` for the full routing guide and
`docs/TROUBLESHOOTING_AUDIO.md` if audio never arrives.
